# 🎵 Infinity Beats - Music Player

A simple and clean web-based music player built with HTML, CSS, and JavaScript. Infinity Beats lets you play songs directly in your browser with a Spotify-inspired UI.

---

## 🌐 Live Demo

> Open `index.html` in your browser to get started!

---

## 📌 Features

- 🎵 Play / Pause songs
- ⏭️ Next & Previous track controls
- 📊 Progress bar to track and seek song position
- ⏱️ Live timer showing current time and total duration
- 🎞️ Animated GIF indicator when a song is playing
- 📄 Song list with individual play buttons
- ℹ️ About page

## 🚀 How to Run

1. **Clone the repository**
```bash
git clone https://github.com/Preetham9638/IBMPROJECT.git
cd IBMPROJECT
```

2. **Open in browser**
```bash
# Just open index.html directly in any browser
open index.html
```

No installations or dependencies needed — it's pure HTML/CSS/JS! ✅
